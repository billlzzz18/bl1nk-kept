# Benchmark assets

`benchmarks/` เก็บข้อมูลเปรียบเทียบที่ต้องรักษาและ regenerate ได้. รายงานข้อความหรือ screenshot ไม่ใช่ source of truth ของตัวเลข.

| Path | Contents | Recreate command | Scope |
|---|---|---|---|
| `data/search_duplicate_release.jsonl` | raw synthetic release benchmark ที่ 10K, 100K และ 1M objects | `cargo run -p kept-core --example benchmark --release -- --objects 10000 100000 1000000 > benchmarks/data/search_duplicate_release.jsonl` | search/index/duplicate candidate reduction regression; ไม่ใช่ production SLO |
| `charts/search_duplicate_release.png` | chart จาก release JSONL | `python3 benchmarks/scripts/render_search_duplicate_chart.py benchmarks/data/search_duplicate_release.jsonl benchmarks/charts/search_duplicate_release.png` | visual comparison ของ raw release data |
| `data/foundation_th_cc0_r1/raw.jsonl` | repeated duplicate-default measurements | `cargo run -p kept-core --example foundation_experiment --release` | public CC0 Thai lexical workload, exact/near-name strata |
| `data/foundation_th_cc0_r1/summary.json` | summary/selection result ของ raw measurements | generated by `foundation_experiment` togetherกับ raw JSONL | selected duplicate defaults; ไม่แทน real filesystem distribution |
| `scripts/render_search_duplicate_chart.py` | deterministic chart renderer | invoked with input JSONL and output PNG | chart must not be edited by hand |

## Required comparison discipline

Every new benchmark set must retain raw rows, command/options, input or corpus revision, Rust version/host metadata, run/repetition policy, correctness/safety gate status and limitations. If data contract differs, label comparison `incomparable`; do not calculate a percentage claim from mismatched runs.

## Current limits

The release benchmark is synthetic deterministic and the 1M row remains a valid committed comparison point. The Foundation experiment uses public CC0 Thai words; it measures duplicate parameter selection only. Neither artifact proves quality for semantic synonyms, homophones, transliteration, real document content, private filesystem distributions or the future 10K reviewed gold corpus.
