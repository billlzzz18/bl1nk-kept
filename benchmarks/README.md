## Acquisition & Grep Benchmark Framework (FFF vs Ripgrep)

ตามข้อกำหนดใน `SPEC.md` หมวด 12 การประเมินสมรรถนะของ `kept` แบ่งออกเป็น 4 ระดับ:

### 1. Component Benchmark (FFF vs `rg`)
- **Metric:** Throughput (MB/s), Search Latency (ms), Resident Memory (RSS MB), Cold vs Warm page cache.
- **Workloads:**
  - Exact literal string grep
  - Multi-line regex grep
  - Multi-pattern grep (OR constraints)
  - Ignore-rule traversal (`.gitignore` + nested rules)
- **Baseline:** Standard `ripgrep` binary (latest release) executed via identical process/sub-process isolation.

### 2. Treatment Benchmark
- วัด Token reduction ratio และ overhead latency ของแต่ละ Admission Treatment:
  - `PASS`: 100% token cost (baseline)
  - `COMPRESS`: 40–60% token cost
  - `SELECT` (Tree-sitter Symbol): 10–25% token cost
  - `DELTA`: 2–10% token cost
  - `REFERENCE`: <1% token cost (~13-20 tokens fixed pointer)

### 3. Workflow Benchmark
- ทดสอบ End-to-end multi-turn scenarios:
  - Repository exploration & understanding
  - Repeated inquiry on unchanged files (zero-token reference loop)
  - Refactoring & symbol-level edit tracking (delta emission)

### 4. Client Benchmark
- วัด impact บน Agent clients (Claude Code, Codex, Custom Agent):
  - Total context emitted reduction (-50% to -80%)
  - Repeated read elimination (>80%)
  - Tool call count reduction
  - Task completion time

## Required comparison discipline

Every new benchmark set must retain raw rows, command/options, input or corpus revision, Rust version/host metadata, run/repetition policy, correctness/safety gate status and limitations. If data contract differs, label comparison `incomparable`; do not calculate a percentage claim from mismatched runs.

## Current limits

The release benchmark is synthetic deterministic and the 1M row remains a valid committed comparison point. The Foundation experiment uses public CC0 Thai words; it measures duplicate parameter selection only. Neither artifact proves quality for semantic synonyms, homophones, transliteration, real document content, private filesystem distributions or the future 10K reviewed gold corpus.
